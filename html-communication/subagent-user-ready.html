One Ice loop.
Bounded delegated work.

Choose a parent-derived child or a Markdown specialist. Both use Ice's model runtime and the same scope, budget, policy-hook, cancellation, and evidence boundaries.

Self

role: "self" snapshots the current parent instructions. Optional child guidance is additive. Fresh history is the default; privileged management tools are never inherited.

File agent

A complete global ~/.ice/agents/name.md wins over the same-name trusted project file. There is no hidden specialist catalog or alias fallback.

Tools

Scoped built-ins plus explicitly registered child-safe parent adapters. Selected MCP tools require actual schemas and host-owned access classifications.

Start without an agent file

{
  "role": "self",
  "task": "Inspect the implementation and report verified evidence.",
  "scope": { "roots": ["src"] },
  "timeoutMs": 120000,
  "execution": { "maxOutputBytes": 16384 },
  "contextMode": "fresh"
}

Use existing directory roots. Individual files belong in scope.targets, not roots. timeoutMs is the real wall-clock deadline and maxOutputBytes caps the complete parent-facing result; there are no per-child turn or tool-call ceilings. self.inheritSkills: true explicitly inherits loaded parent skills; self.mcp: ["docs/search"] selects an authorized MCP operation.

Model selection is not replay

Explicit call model OR file primary
                 ↓ unavailable
            File fallback
                 ↓ unavailable
       Parent model captured at launch

Alternative routes require global ice.subagents.modelSelection.mode: "configured". Availability failures have bounded skip reasons. Policy denials fail closed. Only a proven pre-effect startup failure may consume the second attempt; both attempts share time and output budgets.

A queued job keeps its accepted route and fingerprints. Changed capabilities or unavailable authentication fail explicitly. Restart interrupts live work rather than relaunching it. Edits and external calls with uncertain outcomes are never automatically replayed.

Observe and stop

/agents and /subagents expose existing child views. list_subagent_profiles reports sources, effective tools, models, and skip reasons. Inspect and extend an existing needs_time child rather than launching a duplicate. Set ice.subagents.enabled: false to block new work while preserving owned job inspection and cancellation.

Migration and boundaries

Legacy ~/.ice/agent/agents files are reported in a collision-aware manifest; nothing is moved or deleted. An explicit custom agent directory retains <agentDir>/agents. Settings and credentials remain in their existing locations.

Host Bash, command hooks, and external MCP services are not a sandbox. An adapter must use existing authorized connections and enforce its own external-resource policy. Provider-free tests do not certify every real model provider or independently installed MCP extension.
