# Subagent V2 Regression Ledger

Status: Phase 0 (P0.3) baseline. Companion to [`subagent-rewrite.md`](./subagent-rewrite.md).
Base: `integration/all-worktrees-experimental` at `2d38c5ad5`.
Inventory: 41 test files, 832 test cases (generated by script; counts are `it(`/`test(` occurrences).

## Rules

- **KEEP**: the test stays as is. It targets a module V2 keeps, possibly moved under `src/subagents/`.
- **PORT**: the invariant is kept; the test is rewritten against V2 names and surfaces (`agent`, `agent_control`, `agent_patch`, `ChildRegistry`, `ag_` IDs).
- **REPLACE**: the old behavior is intentionally changed by a locked decision. The new V2 test covers the replacement behavior, and the row names the decision.
- **N/A**: the behavior is removed with no replacement. A reason is required.
- No legacy test may be deleted before its row is resolved and its V2 replacement (if any) is green (P10.1).
- Classification happens at file level here. The 252-case monolith `ice-subagents.test.ts` is classified per theme bucket. **Each of its cases must receive an individual classification when Phase 1 splits the file**, recorded in the "Monolith split log" section below.
